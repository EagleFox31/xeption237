## Principes de design

- **Divulgation progressive** : 1 écran = 1 décision, zéro surcharge cognitive
- Inspiré d'Apple Trade In, Back Market, Nielsen Norman Group
- Adapté au marché camerounais : FCFA, MTN MoMo, Orange Money, Mfoundi Mall
- Design System noir/or cohérent avec l'app Xeption existante
